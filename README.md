# color-lab

A color palette generator with advanced features for designers and developers.

## Features
- Generate harmonious color palettes based on color theory.
- Adjust colors using HSL, OkLCH, and HEX values.
- Export palettes in various formats (CSS, JSON, PNG).

Core functionalties comes for the [colorizr](https://github.com/gilbarbara/colorizr) library.
